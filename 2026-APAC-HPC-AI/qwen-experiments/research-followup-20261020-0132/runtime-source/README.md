# Pinned runtime source inspection

Source files under `extracted/sgl-workspace/sglang/` were selectively extracted from the existing pinned `/scratch/enroot-images/sglang-harbor.sqsh` on the login node, using the installed unsquashfs with two CPU workers. No GPU job was used. The initial `-cat` probe was unsupported by this old unsquashfs executable, leaving four empty placeholder files in this directory; those files are failed probes, not runtime source. The extraction logs and actual source hashes distinguish them. No image or runtime was upgraded.

The native disaggregated decode loop calls `request_receiver.recv_requests()` each iteration. The receiver invokes `recv_skipper.handle(last_batch)` before pulling and broadcasting requests. `SchedulerRecvSkipper.maybe_create()` activates for scheduler_recv_interval > 1; its mode-dependent weights govern polling. This makes a decode-only interval 2 a real supported candidate for reduced receive/broadcast overhead, with a potential admission-delay tradeoff. It does not skip model tokens or change the number of forward passes. Interval 1 remains the default/control. Validate the same installed source on each platform before submission.
