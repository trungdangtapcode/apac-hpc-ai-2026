## Execution shape

The script requests four exclusive 128-core CPU nodes, no GPUs, and at most 90 minutes. It first checks the sealed payload, case, mesh, assignment, and PBS nodefile; loads OpenFOAM 2512; compiles the diagnostic and shared shim on the allocation; and verifies the linked MPICH library. The launcher runs without `LD_PRELOAD`. Each MPI application rank is started through `capture-affinity-exec.py`, which records the launcher's singleton CPU and supplies it to the PMPI shim in the application environment.

Before case preparation or solver work, strict method-3 identity and candidate C probes must both pass. The C probe calls `MPI_Init_thread(MPI_THREAD_SINGLE)`, reports physical host/core/NUMA placement, and makes a collective fail-closed decision. The identity result drives candidate rendering; the candidate validator checks every world rank against the same allocation's intended identity slot. Both the wrapper and PMPI shim must emit 512 successful records. No solver starts if any launcher mask, initialization entry point, affinity restoration, host, core, NUMA, assignment, or source check fails.

One baseline case is decomposed with the frozen default Scotch configuration and initialized once using method-3 identity order. The parent graph guard verifies the actual partition before initialization continues. A complete initialized zero-time field seal is retained. Initialization function-object output is moved out of the baseline after its logs and seals are captured, so each solver copy starts with fresh timer and force output paths.

Four copies are created and run sequentially in `A1, B1, B2, A2` order. A is method-3 identity order; B is the validated candidate order. A per-arm placement probe immediately precedes each solver. The actual solver log must show `MPI_Init_thread` diagnostics for all ranks, restore each rank to the CPU from its probe, and display the expected rank-to-host assignment. Every arm is an independent case tree; `cp -a --reflink=auto` may share copy-on-write data, but regular file inodes must remain distinct. The script checks available filesystem space before each copy and checks that zero fields match the baseline before and after every solver.

Each arm runs the unchanged `simpleFoam -parallel` case to Time 150. The native validator independently checks 150 ordered solver times, 149 finite wall-time samples, all fixed iteration counts, force rows, and native/timer agreement. All samples and native output remain intact. The report gives per-run distributions, the two order-balanced paired mean differences, and descriptive force trace differences. It defines no cross-arm numerical tolerance and treats no time step as an independent experimental replication.

These are fail-closed time guards, not completion guarantees or measured solver changes.
