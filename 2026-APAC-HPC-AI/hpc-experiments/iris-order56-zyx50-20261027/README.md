# Single-arm 50-step zyx horizon extension

This preparation extends the zyx run from 30 to 50 steps using the same initialized `order-zyx` source and the same fixed-iteration numerical work. It checks whether measured throughput and transient numerical behavior persist through steps 31–50. It is one arm only: it is not a matched 50-step comparison, a full 150-step run, or an official score.

The reverse-order parent run 2294132 completed in 1,870 seconds on 56 CPUs. zyx ran first at 22.290292514 seconds per step; xyz ran second at 28.367224538 seconds per step, an observed 21.42% lower mean for zyx in that pair. The native minimum-sample recommendations were 8 for zyx and 111 for xyz, with only 29 measured intervals per arm. The pair is confidence-limited and still has order, environment, and thermal effects. This extension uses zyx only to collect 49 intervals and inspect numerical output beyond step 30; it cannot establish a comparative solver speedup.

The run retains every measured interval. Its report includes descriptive summaries for intervals labeled steps 2–30 (29 samples) and 31–50 (20 samples), alongside all 49 raw timings. Those segments are not filters and do not discard slow observations. Native checks require exactly solver steps 1–50, 49 wall-clock-function rows for steps 2–50, finite Cd output for all 50 steps, and the expected fixed iteration count for every step. The report also preserves native confidence warnings, Cd, resources, affinity evidence, source/copy checks, and before/after procfs snapshots. Procfs counters cover the whole node; they do not measure memory bandwidth or attribute all changes to the solver process.
