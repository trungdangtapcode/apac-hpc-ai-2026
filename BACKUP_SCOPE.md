# Backup scope and exclusions

The snapshot considers regular files in `/home/apacsc42/2026-APAC-HPC-AI` and `/home/apacsc42/workspace`. It does not archive the whole home directory. OS installations, Codex credentials/chat state, shell history, SSH keys and cloud credentials are outside the source scope.

Container `home` mounts, nested `.git` databases, cache/virtual environments, sockets, private VPN logs/session caches and rootless Docker runtime installations are excluded. The original two upstream repositories have separate Git bundles. Operational VPN source is intended to be retained only through an inspected source allowlist; authentication material is never included. Every excluded path/category and any unreadable or changing file is listed in the scan/snapshot reports. The exclusion of recreatable environments does not imply that every dependency is already pinned.

Large retained files are external content-addressed objects. Exact benchmark input JSON, request JSONL and raw collection tar/zip archives are preserved, including duplicates represented by shared hashes. Tar/zip members are inspected for secret signatures and authentication filenames before their archive enters the portable set. Synthetic benchmark inputs are hashed without a secret scan because they are generated public-text workloads. Model/client container binaries are opaque hashed local runtime objects and must be reviewed separately before redistribution.

Public model weight shards under `/scratch/models` are not copied into this snapshot. Model configuration, tokenizer files, shard names/sizes, available source checksum contracts and model identity are retained under `external-runtime/` or in original experiment records. Obtain the same public checkpoint and validate it before reproduction. The exact SGLang and AIPerf container files under `/scratch/enroot-images` are included as external local objects because recreating them from a mutable image tag may change behavior. Hardware drivers, cluster networks, Slurm/PBS installations and the H100 filesystem are outside this local archive. Remote-only results cannot be claimed as backed up while VPN is unavailable.

Existing Vietnamese historical documents are preserved byte-for-byte as evidence. New import/backup documents are English. Presentation snapshots remain snapshots; no new official score or organiser submission is created. No license is imposed on third-party source, benchmark text or supplied assets; their existing notices remain applicable.

Two damaged collection archives, if listed in `backup/scan-results.json` under `local_only_review`, are preserved byte-for-byte in `local-review-objects/`. They are local evidence with incomplete archive-member inspection and **must not be automatically published** with the normal object set. Their manifest entries explicitly require distribution review. The object store directory is owner-only on the source machine. This preserves failed capture evidence without treating malformed archives as approved upload content.
