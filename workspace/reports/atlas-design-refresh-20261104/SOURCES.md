# Visual direction and asset provenance

The owner requested a stronger UI with image generation or Pinterest inspiration. Pinterest searches identified the pins below, but direct inspection returned HTTP 403; no claim is made that their full artwork was inspected. The accessible original Untitled UI reference was inspected via its linked preview image. No third-party reference image is shipped in the site.

- Pinterest: https://ru.pinterest.com/pin/304063412340730255/ — search result for dashboard filter UI; direct access blocked.
- Pinterest: https://ru.pinterest.com/pin/442830575855885551/ — dashboard UI/UX search result; direct access blocked.
- Jordan Hughes / Untitled UI: https://dribbble.com/shots/23564969-Sidenav-and-UI-components-Untitled-UI — dark side navigation and clearly grouped workspace content. Adapted as general visual direction, not copied screens or components.
- Supplemental search reference: https://dribbble.com/shots/25551237-Charts-Graphs-Koala-UI — dashboard information hierarchy. Not used as an image asset.

An original image was generated with the built-in imagegen tool for the sidebar: a dark abstract translucent fluid mesh becoming fine computational filaments, with restrained violet and peach rim light. It has no text, measurements or scientific claims. The same image is retained as PNG and exported to WebP at its original 1024×1536 dimensions for delivery. The site embeds the WebP so it works offline. The PNG is retained through the archive’s large-object mechanism; the build depends only on the directly tracked WebP.

The generated art is decorative. Actual experiment diagrams remain source-derived SVG, and all figures, counts, metric units and evidence classes remain unchanged.
